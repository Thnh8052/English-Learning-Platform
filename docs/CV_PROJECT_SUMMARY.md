# CV Project Summary

## Short Description

English Learning Platform is a full-stack learning management web application for students, teachers, and admins. The system supports course and lesson management, quiz generation, speaking practice, writing submissions, role-based dashboards, authentication, file uploads, and AI-assisted feedback for language learning.

## CV Bullet Points

- Built a full-stack English learning platform using React, Vite, Node.js, Express, MongoDB, and Mongoose.
- Implemented JWT authentication, role-based access control, and separate workflows for students, teachers, and admins.
- Developed course, lesson, module, quiz, submission, grading, and review features with RESTful API endpoints.
- Integrated Cloudinary for media uploads and SendGrid for password reset email delivery.
- Added AI-assisted learning features including quiz generation, writing score calculation, file parsing, and speech-to-text support.
- Designed reusable frontend pages and components for dashboards, course browsing, lesson playback, submissions, and profile management.

## One-Line Version

Full-stack AI-assisted English learning platform with course management, quizzes, speaking/writing assessment, role-based dashboards, JWT authentication, and MongoDB-backed REST APIs.

## Technologies

React, Vite, Node.js, Express, MongoDB, Mongoose, JWT, Cloudinary, SendGrid, Axios, CSS Modules, Recharts, Framer Motion, AI API integrations.
